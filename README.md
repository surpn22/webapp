# OCR เอกสาร (ไทย · English)

เว็บแอปในเครื่องสำหรับ OCR เอกสาร แยกงานเป็นโฟลเดอร์ หน้าตาคล้ายแชต ใช้โมเดล OpenThai2.0 ที่อยู่ใน `~/thai-ocr`
ไฟล์และผลทั้งหมดอยู่ในเครื่อง ไม่มีการส่งออกไปภายนอก

## เปิดแอป

```bash
~/thai-ocr/webapp/start.sh
```

เบราว์เซอร์จะเปิด http://127.0.0.1:8765 เอง ปิดแอปด้วย Ctrl+C ในหน้าต่าง Terminal
ครั้งแรกจะ build หน้าเว็บก่อน (ต้องมี Node) ใช้เวลาไม่กี่วินาที

## วิธีใช้

1. แถบซ้ายมีสองแบบให้เลือก
   - **＋ แชตใหม่**: แชตเดี่ยว ตั้งชื่อตามไฟล์แรกที่ส่งให้เอง
   - **＋ โฟลเดอร์ใหม่**: ใช้จัดกลุ่มแชตตามเรื่อง เช่น "สิ่งแวดล้อม" "กฎหมาย" เปิดโฟลเดอร์แล้วแนบไฟล์ได้เลย จะเกิดแชตใหม่ในโฟลเดอร์นั้น
   - ย้ายแชตเข้า/ออกจากโฟลเดอร์ด้วย ⇄ เปลี่ยนชื่อด้วย ✎ ลบด้วย 🗑 (ลบโฟลเดอร์จะลบแชตข้างในด้วย)
2. **แนบไฟล์** ในช่องแชตด้านล่างด้วยปุ่ม 📎 หรือลากไฟล์มาวาง รับ PDF, PNG, JPG, TIFF, WEBP ได้หลายไฟล์พร้อมกัน
3. **เลือกโมเดล** ที่ปุ่มมุมขวาของช่องแชต แล้วกดส่ง ↑ (แอปจำโมเดลที่เลือกล่าสุดไว้)
   - **OCR Text**: ข้อความไทย/อังกฤษล้วน ไม่ถึง 1 วินาทีต่อหน้า ไม่แยกตาราง และอ่านลายมือได้ไม่ดี
   - **OCR Markdown**: ได้ Markdown พร้อมตาราง แม่นกว่า แต่ใช้ราว 25–35 วินาทีต่อหน้าบนเครื่องนี้ ครั้งแรกต้องรอโหลดโมเดล 2.5 GB ก่อน
4. ผลจะขึ้น **ทีละหน้า** ในแชต กดยกเลิกได้ระหว่างทำ (งานจะหยุดหลังหน้าที่กำลังอ่านเสร็จ)
5. ปุ่มในการ์ดผล:
   - **ดาวน์โหลด .txt** (หรือ `.md`) หรือคัดลอก ได้ผลดิบจากโมเดลทุกตัวอักษร
   - **เทียบกับต้นฉบับ**: ดูรูปหน้าเอกสารคู่กับผล OCR (ใช้ลูกศร ← → เปลี่ยนหน้า)
   - **รันใหม่ด้วยอีกโมเดล**: ไม่ต้องอัปโหลดซ้ำ
6. **ค้นหา** ที่มุมขวาบน ในแชตค้นเฉพาะแชตนั้น ในหน้าโฟลเดอร์ค้นทุกแชตในโฟลเดอร์ ค้นได้ทั้งคำไทยและอังกฤษ (ไม่สนตัวพิมพ์เล็กใหญ่) กดผลเพื่อเปิดหน้านั้น

### เรื่องความแม่นยำ

- แอปส่งภาพเข้าโมเดลแบบเดียวกับ `ocr_text.py` และ `ocr_markdown.py` (PDF วาดที่ 200 dpi, รูปภาพส่งตามต้นฉบับ)
  ผลที่ได้จึงตรงกับสคริปต์เดิมทุกตัวอักษร ตรวจได้ด้วย `tests/accuracy_test.py`
- OCR Text: บรรทัดที่ **ขีดเส้นสีส้ม** คือบรรทัดที่โมเดลมั่นใจต่ำกว่า 90% ควรตรวจกับต้นฉบับ
  และโมเดลตัดบรรทัดที่มั่นใจต่ำกว่า 80% ทิ้งเอง (มักเป็นตราประทับหรือลายมือ) กดดูรายการที่ถูกตัดได้ใต้แต่ละหน้า
- เอกสารที่มีลายมือหรือตาราง ใช้โมเดล **OCR Markdown** จะได้ผลดีกว่ามาก

### หน่วยความจำ

โมเดล OCR Markdown ใช้หน่วยความจำมาก (GPU ของ Mac ใช้ RAM ร่วมกับเครื่อง) หลังใช้งานเสร็จ
กด **ปล่อยหน่วยความจำ** ที่ล่างแถบซ้ายได้ ครั้งต่อไปที่ใช้โหมดนี้จะโหลดใหม่เอง

### ถ้าปิดแอประหว่าง OCR

เปิดแอปใหม่แล้วงานนั้นจะขึ้นว่า "ถูกขัดจังหวะ" กด **ทำต่อ** แอปจะอ่านเฉพาะหน้าที่ยังไม่เสร็จ

## ข้อมูลอยู่ที่ไหน

- `data/app.db`: โฟลเดอร์ แชต ประวัติแชต และผล OCR รายหน้า (SQLite)
- `data/folders/<เลขแชต>/`: ไฟล์ต้นฉบับตามที่อัปโหลด (ชื่อเดิมเก็บในฐานข้อมูล)

สำรองข้อมูลด้วยการคัดลอกโฟลเดอร์ `data` ทั้งโฟลเดอร์ตอนปิดแอป

## ทดสอบ

```bash
cd ~/thai-ocr/webapp
../.venv/bin/python tests/accuracy_test.py      # เทียบผลจากแอปกับสคริปต์เดิมทีละตัวอักษร (แอปต้องเปิดอยู่)
```
